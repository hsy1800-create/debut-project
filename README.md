# 데뷔 프로젝트: 기획사를 살려라

6학년 사회 「우리나라 경제의 특징」 단원(1~7차시)을 기획사 경영 이야기로 풀어 보는 게임입니다.
세린·유하·태오·이안이 데뷔를 준비하는 작은 기획사의 대표가 되어, 장마다 경제 개념으로 위기를 넘깁니다.

- 게임 주소: https://hsy1800-create.github.io/debut-project/
- 1장 시장·가계·기업 / 2장 시장 경제와 경쟁 / 3장 가계의 합리적 선택 / 4장 기업의 역할 / 5장 근로자의 권리 / 6장 기업의 자유와 사회적 책임 / 7장 경제성장
- 진행 상황은 각 기기(패드)에 저장되어, 차시마다 한 장씩 이어서 할 수 있습니다.
- 파일 하나(index.html)에 그림과 코드가 모두 들어 있습니다.

## 고치는 방법

- 새 그림 넣기: `art/` 폴더에 그림을 넣고 `python tools/import_art.py` → `python tools/build.py` (자세한 내용은 `AGENTS.md`, 그림 프롬프트는 `art/PROMPTS.md`)
- 대사와 미션: `src/story.js` / 화면 모양: `src/style.css` / 게임 진행: `src/engine.js`
- 고친 뒤 `python tools/build.py`를 실행하면 `index.html`이 새로 만들어집니다.

## 개념기반 탐구수업 후 복습 운영

게임은 한 주소로 유지하고, 웨일 클래스의 네 수업 모듈에 같은 주소와 해당 장의 안내를 올립니다. 수업에서 자료와 사례를 탐구한 뒤 게임으로 선택을 다시 적용합니다.

| 모듈 | 차시 | 수업 뒤 할 게임 | 멈출 곳 |
| --- | --- | --- | --- |
| 생각 열기 | 1차시 | 1장: 시장·가계·기업 | 1장 완료 |
| 탐구하기 1 | 2~4차시 | 차시별 2장 → 3장 → 4장 | 각 장 완료, 모듈 마지막은 4장 |
| 탐구하기 2 | 5~6차시 | 차시별 5장 → 6장 | 각 장 완료, 모듈 마지막은 6장 |
| 확장하기 | 7차시 | 7장과 엔딩 | 엔딩 확인 |

- 매 차시 복습은 해당 장만 5~10분 정도 하도록 안내합니다. 학생별 속도에 따라 조절합니다.
- 장을 완료하면 다음 장으로 넘어가지 않고 종료합니다. 다음 수업 뒤 같은 기기·같은 브라우저에서 이어 합니다.
- 복습 뒤 “내 선택 → 영향을 받은 사람 → 그렇게 생각한 근거”를 두 문장으로 웨일 클래스에 제출합니다. 게임 점수보다 설명의 근거를 살핍니다.
- 진행 기록은 브라우저에 저장됩니다. 다른 기기로 자동 동기화되거나 웨일 클래스에 자동 제출되지는 않습니다.
- 모든 수업을 마친 뒤에는 전체 1~7장을 다시 하며 처음 선택과 달라진 이유를 설명할 수 있습니다.
