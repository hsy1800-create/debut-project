# 데뷔 프로젝트: 기획사를 살려라

6학년 2학기 사회 「2. 시장경제와 국가 간 거래」 단원(13차시)을 기획사 경영 이야기로 풀어 보는 게임입니다.
세린·유하·태오·이안이 데뷔를 준비하는 작은 기획사의 대표가 되어, 장마다 경제 개념으로 위기를 넘깁니다.

- 게임 주소: https://hsy1800-create.github.io/debut-project/
- 1장 시장·가계·기업 / 2장 시장 경제와 경쟁 / 3장 가계의 합리적 선택 / 4장 기업의 역할 / 5장 근로자의 권리 / 6장 기업의 자유와 사회적 책임 / 7장 경제성장 / 8장 경제성장의 그늘과 해결 / 9장 무역의 뜻과 까닭 / 10장 상호의존과 경쟁
- 엔딩은 10장을 마친 뒤 게이지 점수로 정해집니다. 7~9장 끝에는 다음 장으로 이어지는 "다음 화 예고"가 나옵니다.
- 진행 상황은 저장하지 않습니다. 새로고침하거나 다시 접속하면 누구나 첫 화면에서 시작합니다.
- 파일 하나(index.html)에 그림과 코드가 모두 들어 있습니다.

## 고치는 방법

- 새 그림 넣기: `art/` 폴더에 그림을 넣고 `python tools/import_art.py` → `python tools/build.py` (자세한 내용은 `AGENTS.md`, 그림 프롬프트는 `art/PROMPTS.md`)
- 대사와 미션: `src/story.js` / 화면 모양: `src/style.css` / 게임 진행: `src/engine.js`
- 고친 뒤 `python tools/build.py`를 실행하면 `index.html`이 새로 만들어집니다.

## 개념기반 탐구수업 후 복습 운영

게임은 한 주소로 유지하고, 웨일 클래스의 네 수업 모듈에 같은 주소와 해당 장의 안내를 올립니다. 수업에서 자료와 사례를 탐구한 뒤 게임으로 선택을 다시 적용합니다.

| 모듈 | 차시 | 수업 뒤 할 게임 |
| --- | --- | --- |
| 생각 열기 | 1~2차시 | 프롤로그 |
| 탐구하기 1 | 3~6차시 | 1~4장(2-1), 5장(2-2), 6장(2-3) |
| 탐구하기 2 | 7~11차시 | 7·8장(3-1), 9장(3-2), 10장(3-3) |
| 확장하기 | 12~13차시 | 엔딩과 결과 카드 |

- 프롤로그는 1장 첫머리(삼촌의 편지, 이름 정하기, 멤버 소개)이며 미션 1-1이 나오기 전까지입니다.
- 매 차시 복습은 해당 장만 5~10분 정도 하도록 안내합니다. 학생별 속도에 따라 조절합니다.
- 장을 완료하면 다음 장으로 넘어가지 않고 종료합니다. 다음 수업에는 첫 화면의 ‘장 고르기’로 원하는 장을 선택합니다. 장 고르기 화면에는 장마다 모듈 이름이 함께 나옵니다.
- 복습 뒤 “내 선택 → 영향을 받은 사람 → 그렇게 생각한 근거”를 두 문장으로 웨일 클래스에 제출합니다. 게임 점수보다 설명의 근거를 살핍니다.
- 진행 기록은 현재 열린 페이지에서만 유지합니다. 브라우저나 서버에 저장하지 않으며, 페이지를 닫거나 새로고침하면 이름·점수·포카·완료 기록이 초기화됩니다.
- 엔딩과 데뷔 기록 카드는 10장을 마치면 바로 나옵니다. 엔딩은 지금 열린 페이지에서 푼 미션 점수로 정해지므로, 확장하기에서는 1~10장을 이어서 다시 하며 처음 선택과 달라진 이유를 설명할 수 있습니다.
